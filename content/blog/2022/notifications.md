Summary: Mountain Duck 4.12 introduces a new Notifications tab in Preferences that allows customizing the notifications to be displayed. In particular it allows fine tuning which notifications to receive when file changes are detected on the server and background synchronization activity.

[Mountain Duck 4.12](https://mountainduck.io/changelog/) introduces a new [Notifications](https://docs.cyberduck.io/mountainduck/preferences/#notifications) tab in Preferences that allows customizing the notifications to be displayed. In particular it allows fine tuning which notifications to receive when file changes are detected on the server and background synchronization activity.
