This release features a lot of changes under the hood with a new [WebDAV](http://code.google.com/p/sardine/ "Sardine") protocol implementation and polishing the user interface on Windows. My personal favorite is the support for Trackpad gestures on Mac OS X to navigate folders. Refer to the [changelog](http://cyberduck.ch/changelog/ "changelog") for the rest.

*The version for the AppStore is currently in review and expected to be available shortly.* Now available in the AppStore!
