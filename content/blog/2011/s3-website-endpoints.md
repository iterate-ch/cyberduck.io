Summary: Amazon now supports hosting static websites on S3. The latest snapshot build of Cyberduck supports configuring website distributions for S3 buckets. Update: You can now also configure Website Configuration Endpoint Distributions with CloudFront CDN.

Amazon now supports [hosting static websites](http://aws.typepad.com/aws/2011/02/host-your-static-website-on-amazon-s3.html) on S3. The latest [snapshot build](http://trac.cyberduck.ch/wiki/help/en/faq#NightlyandBetabuilds) of Cyberduck supports configuring website distributions for S3 buckets.

[![](http://sudo.ch/wp/uploads/2011/02/S3-Website-Configuration.png "S3 Website Configuration")](http://sudo.ch/wp/uploads/2011/02/S3-Website-Configuration.png)  
**Update:** You can now also configure [Website Configuration Endpoint Distributions with CloudFront CDN](http://trac.cyberduck.ch/wiki/help/en/howto/cloudfront#WebsiteConfigurationEndpointDistributionswithCloudFrontCDN).
