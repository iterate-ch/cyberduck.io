Summary: The latest snapshot build of Cyberduck for Mac & Windows allows the configuration of access logging for Google Cloud Storage. The Info panel lets you choose the target bucket for log files to be delivered to. The logs in Google Storage are available in 24 hour intervals.

The latest [snapshot build](http://trac.cyberduck.ch/wiki/help/en/faq#SnapshotandBetabuilds) of Cyberduck for Mac & Windows allows the configuration of access logging for [Google Cloud Storage](http://code.google.com/apis/storage/). The Info panel lets you choose the target bucket for log files to be delivered to. The logs in Google Storage are available in 24 hour intervals.
