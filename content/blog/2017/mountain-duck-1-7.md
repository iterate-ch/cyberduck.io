Mountain Duck 1.7 is now available with a focus on [fixes for stability and performance improvements](https://mountainduck.io/changelog/) by an improved connection management. On Windows, the user interface is completely rewritten based on the Windows Presentation Foundation.

Mountain Duck 2.0 coming this spring will support [transparent client-side encryption using Cryptomator](/2017/01/19/cryptomator/) interoperable vaults to secure your data on any server or cloud storage mounted.
