The [cyberduck.ch](http://cyberduck.ch/) now supports [access keys](http://www.alistapart.com/articles/accesskeys/) which means you can download the application using Control-D or change to the [features](http://cyberduck.ch/features.php) page using Control-F. Also I have just noticed Google now displays a submenu with links to the [features](http://cyberduck.ch/features.php), [help](http://cyberduck.ch/help), [donate](http://cyberduck.ch/donate) and [development](http://trac.cyberduck.ch/) pages if cyberduck.ch is the top search result (as shown below). No idea if they do this by hand (anyone knows for sure?).
