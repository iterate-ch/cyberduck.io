We have made a number of improvements supporting two factor authentication with one time passcode for SFTP. The latest [minor update](http://cyberduck.io/changelog/) of Cyberduck 4.4 has been tested to work flawlessly with installations running the [Google Authenticator](https://code.google.com/p/google-authenticator/) PAM module with OpenSSH keyboard interactive authentication or similar setups.

Give it a try in the latest [beta](https://trac.cyberduck.io/wiki/help/en/faq#SnapshotandBetabuilds) build available for Mac & Windows.

***Update***. Documentation now available in the [wiki](https://trac.cyberduck.io/wiki/help/en/howto/sftp#GoogleAuthenticator "wiki").
