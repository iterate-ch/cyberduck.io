We are thrilled to announce the release of [Mountain Duck 4](https://mountainduck.io/) – the premier choice to mount server and cloud storage as a disk in Finder on macOS and the File Explorer on Windows.

![](/2020/06/Screenshot-Windows-Mountain-Duck-4.png)

### File History with recent changes

Version 4 adds a [file history](https://trac.cyberduck.io/wiki/help/en/howto/mount/sync/history) with a detailed view of transfers in progress and history of recently edited files on your computer and on the server. Users can select an item to quickly reveal the changed file in the file explorer.

![](/2020/06/menu_history_macos.png)

### Labels for Bookmarks

![](/2020/06/Edit-Bookmark-Windows.png)

Assigning labels to bookmarks allows grouping bookmarks in folders in the menu further enhancing the unobtrusive [user interface](https://trac.cyberduck.io/wiki/help/en/howto/mount/interface).

### Features for Teams

[Locking](https://trac.cyberduck.io/wiki/help/en/howto/mount/locking) files prevents conflicting edits from others while editing a document. Support has been introduced locking files when connecting to a WebDAV server. Additionally, locking for protocols with no native lock support using lock owner files has been implemented to allow alerts for concurrent edits in Microsoft Office.

![](/2020/06/File-in-Use-Microsoft-Word-Windows.png)

Also when working with versioned buckets in S3, users can open and revert [previous versions](https://trac.cyberduck.io/wiki/help/en/howto/mount/versions) of files.

![](/2020/06/contextmenu_versions_windows.png)
