In a spring cleaning effort we have removed support for Dropbox, Google Drive and Azure in Cyberduck for the upcoming [4.3](http://trac.cyberduck.ch/milestone/4.3) release. This allows us to focus on improving support for [S3](http://trac.cyberduck.ch/wiki/help/en/howto/s3) and open cloud storage standards (speak [Open Stack](http://www.openstack.org/) Swift) and the long supported FTP/SFTP and WebDAV protocols.

We reserve the option to reintroduce support for Azure ([#6521](http://trac.cyberduck.ch/ticket/6521)) and Google Drive ([#6976](http://trac.cyberduck.ch/ticket/6976)) when time allows and user demand is significant.

**Update **The latest snapshot builds for Mac & Windows reintroduce support for [Azure Storage](https://trac.cyberduck.io/wiki/help/en/howto/azure).
