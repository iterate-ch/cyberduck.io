We released [4.4](https://trac.cyberduck.ch/milestone/4.4) some hours ago. Due to various issues in the build and code signing process we had to issue a hot fix update (**13582**) that fixes

-   Crash on launch on OS X 10.6
-   *Check for Update… *disabled
-   Code signature verification issue
-   Java installation prompt

If you have installed a build of 4.4 prior *13582* (Check in *About *→ *Cyberduck*), make sure to manually [reinstall](https://update.cyberduck.ch/Cyberduck-4.4.zip).

The update is currently in review for the Mac App Store.
