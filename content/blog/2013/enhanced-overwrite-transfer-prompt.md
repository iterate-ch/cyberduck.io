The latest [4.4](https://trac.cyberduck.ch/milestone/4.4) snapshot builds feature an updated overwrite transfer prompt that shows much clearer if a file is to be included in the transfer given the selected transfer action. In addition to *Resume*, *Overwrite*, *Rename transferred* file, *Rename existing* file or *Skip* existing, a new option *Compare* only includes duplicate files that do not match in size, modification date and checksum like when synchronizing folders.
