Summary: The latest snapshot build allows to edit container metadata for containers in HP Cloud, Rackspace Cloud Files or any other OpenStack Swift service. Useful to edit default index (X-Container-Meta-Web-Index) and error (X-Container-Meta-Web-Error) documents.

The latest [snapshot build](https://trac.cyberduck.ch/wiki/help/en/faq#SnapshotandBetabuilds) allows to edit container metadata for containers in HP Cloud,  Rackspace Cloud Files or any other OpenStack Swift service. Useful to edit default index *(X-Container-Meta-Web-Index)* and error *(X-Container-Meta-Web-Error) *documents.
