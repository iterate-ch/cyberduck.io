Summary: Cyberduck CLI is now available for the growing ARM ecosystem. Run the universal file transfer tool on AWS EC2 A1 instance types or Raspberry Pis for example. Both DEB and RPM package types are available in 32bit and 64bit for ARM. The regular installation instructions apply.

[Cyberduck CLI](https://duck.sh/) is now available for the growing ARM ecosystem. Run the universal file transfer tool on [AWS EC2 A1 instance types](https://aws.amazon.com/ec2/instance-types/a1/) or Raspberry Pis for example. Both DEB and RPM package types are available in 32bit and 64bit for ARM. The regular [installation instructions](https://duck.sh/#linux) apply.
