We previously only had mirror repository for [Cyberduck on GitHub](https://github.com/iterate-ch/cyberduck) and managed pull requests for changes on our own Git server and mirrored all changes to a SVN repository which was used to display a [timeline](https://trac.cyberduck.io/timeline) of changes in Trac.

We are now using the repository on GitHub as the primary source root and accept [pull requests](https://github.com/iterate-ch/cyberduck/pulls) at the same place. Previous [milestone history](https://github.com/iterate-ch/cyberduck/milestones?direction=desc&sort=due_date&state=closed) has been preserved. This will make contributions more straightforward and simplify the development setup for many.

### Issues

We now use Github as well to manage all [issues](https://github.com/iterate-ch/cyberduck/issues) containing bug reports or feature requests. We have migrated all previous **11919** tickets opened in [Trac](https://trac.cyberduck.io/query) since 2005 to GitHub.

### Documentation

Additionally we will also retire the current documentation in the [Wiki](https://trac.cyberduck.io/wiki) and move it to [docs.cyberduck.io](https://docs.cyberduck.io/). Contributions to the documentation written in Markdown are welcome can be made by opening a [pull request](https://github.com/iterate-ch/docs/pulls).
