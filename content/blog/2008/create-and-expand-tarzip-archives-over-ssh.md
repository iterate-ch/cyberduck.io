A new previously [requested feature](http://trac.cyberduck.ch/ticket/2376) will make it into the upcoming 3.1 release: On the server side archive creation and expanding for TARs and ZIPs with a click of a button.

[![Support to create and expand archives](http://sudo.ch/wp/uploads/2008/12/archive-500x474.png "Support to create and expand archives")](http://sudo.ch/wp/uploads/2008/12/archive.png)

**Note**: This feature does only work for SFTP connections.

Try it out yourself using the latest available [nightly build](http://update.cyberduck.ch/nightly/) of Cyberduck.
