As already noted by [macapper.com](http://macapper.com/2008/04/21/cyberduck-3-flaps-wings-but-does-it-fly/), the just released [Beta 2](http://cyberduck.ch/Cyberduck-3.0b2.dmg) of Cyberduck 3 adds the feature to open the corresponding web address of a file selected in Cyberduck with your default web browser. For this feature to work, you have to specify a reasonable default path in your bookmark (e.g. */home/dkocher/public\_html/*) which must be the directory accessed by the web server as your document root. Using an Apache webserver, this is the *DocumentRoot* directive. Also in the bookmark setting, you can edit the Web URL which allows you to enter the *HTTP* URL of the webserver using a different hostname.

[![](http://sudo.ch/wp/uploads/2008/04/openurl-479x300.jpg "Open Web URL")](http://sudo.ch/wp/uploads/2008/04/openurl.jpg)

Check this out in the the latest [nightly build](http://update.cyberduck.ch/nightly/). Mac OS X 10.4 or later required.
