The next major release of Cyberduck will support WebDAV. [WebDAV](http://webdav.org/), an acronym for *Web-based Distributed Authoring and Versioning*, is described as “…a set of extensions to the HTTP protocol which allows users to collaboratively edit and manage files on remote web servers”.

[![webdav](http://sudo.ch/wp/uploads/thumb-webdav.jpg)](http://sudo.ch/wp/uploads/webdav.jpg)

Although, the Finder.app does support WebDAV, first comparative tests show performance is much better in Cyberduck and browsing feels snappier. Because [.mac](http://www.mac.com/) is based on WebDAV, it will also be possible to access your [iDisk](http://www.apple.com/dotmac/idisk.html) using Cyberduck by mounting the URL `http://idisk.mac.com/membername` as described in this [support document](http://docs.info.apple.com/article.html?artnum=51679).

Cyberduck 3.0 is expected to be released later this next month. The current [nightly build](http://update.cyberduck.ch/nightly/) (use with caution) is available for testing.
