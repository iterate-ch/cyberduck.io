Summary: As we are speaking of the cloud distribution features in the last posts, Cyberduck 3.1 will also have a pre-configured protocol setting for MobileMe iDisk. You are no more required to enter the WebDAV protocol connection parameters manually. Try it out yourself using the latest available nightly build of Cyberduck.

As we are speaking of the cloud distribution features in the last posts, Cyberduck 3.1 will also have a pre-configured protocol setting for [MobileMe iDisk](http://www.apple.com/mobileme/features/idisk.html). You are no more required to enter the WebDAV protocol connection parameters manually.

[![](http://sudo.ch/wp/uploads/2008/11/idisk.png "MobileMe iDisk")](http://sudo.ch/wp/uploads/2008/11/idisk.png)

Try it out yourself using the latest available [nightly build](http://update.cyberduck.ch/nightly/) of Cyberduck.
