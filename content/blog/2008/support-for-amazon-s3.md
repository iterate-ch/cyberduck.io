It allows you to transfer files to your S3 account and browse the S3 buckets and files in a hierarchical way as you are used to with other remote file systems supported by Cyberduck.

The next major release of Cyberduck will support [Amazon S3](http://aws.amazon.com/s3). I have integrated the excellent open source library [JetS3t](http://jets3t.s3.amazonaws.com/index.html) into Cyberduck. It allows you to transfer files to your S3 account and browse the S3 buckets and files in a hierarchical way as you are used to with other remote file systems supported by Cyberduck.

[![Amazon S3 Browser](http://sudo.ch/wp/uploads/thumb-AmazonS3Browser.jpg)](http://sudo.ch/wp/uploads/AmazonS3Browser.jpg)

Cyberduck 3.0 is expected to be released later this month. The current [nightly build](http://update.cyberduck.ch/nightly/) (use with caution) is available for testing.
