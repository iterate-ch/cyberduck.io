Summary: All cloud storage providers supported now allow the configuration of an index file that is delivered for a request to the root of path of content distribution. Previously this was supported only for CloudFront but is now available for Google Cloud Storage and Akamai distributions with Rackspace Cloudfiles as well in the latest snapshot build.

All cloud storage providers supported now allow the configuration of an index file that is delivered for a request to the root of path of content distribution. Previously this was supported only for [CloudFront](http://trac.cyberduck.ch/wiki/help/en/howto/cloudfront#IndexFile) but is now available for [Google Cloud Storage](http://trac.cyberduck.ch/wiki/help/en/howto/googlestorage#IndexFile) and [Akamai distributions](http://trac.cyberduck.ch/wiki/help/en/howto/akamai#IndexFile) with Rackspace Cloudfiles as well in the latest snapshot build.
