The latest [snapshot builds](http://trac.cyberduck.ch/wiki/help/en/faq#SnapshotandBetabuilds) for Mac support new features introduced in OS X 10.8. This includes Gatekeeper support (The application is now signed with a Mac Developer ID certificate issued by Apple), support for the [notification center](http://support.apple.com/kb/HT5362) instead of relying on [Growl](http://growl.info/) and most importantly HiDPI resolution artwork for Retina displays.
