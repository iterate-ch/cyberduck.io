Summary: In addition to the existing cloud storage providers Amazon S3 and Rackspace Cloudfiles, support for the recently announced Google Storage is on track. Interested parties having access to the currently invite-only service in Google Labs are welcome to give it a try using the latest snapshot build of Cyberduck.

In addition to the existing cloud storage providers [Amazon S3](http://trac.cyberduck.ch/wiki/help/en/howto/s3) and [Rackspace Cloudfiles](http://trac.cyberduck.ch/wiki/help/en/howto/cloudfiles), support for the recently announced [Google Storage](http://trac.cyberduck.ch/wiki/help/en/howto/googlestorage) is on track. Interested parties having access to the currently [invite-only service in Google Labs](http://code.google.com/apis/storage/) are welcome to give it a try using the latest [snapshot build](http://update.cyberduck.ch/nightly/) of Cyberduck.
