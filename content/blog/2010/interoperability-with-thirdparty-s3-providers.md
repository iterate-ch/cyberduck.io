Summary: The latest snapshot builds of Cyberduck have improved performance and interoperability with thirdparty S3 cloud storage providers such as Dunkel Cloud Storage and Eucalyptus Walrus implementations. Let me know if you run your own cloud storage and run into interopability issues with Cyberduck.

The latest [snapshot builds](http://update.cyberduck.ch/nightly/) of Cyberduck have improved performance and interoperability with thirdparty S3 cloud storage providers such as [Dunkel Cloud Storage](http://trac.cyberduck.ch/wiki/help/en/howto/dunkel) and [Eucalyptus Walrus](http://trac.cyberduck.ch/wiki/help/en/howto/eucalyptus) implementations. [Let me know](mailto:feedback@cyberduck.ch) if you run your own cloud storage and run into interopability issues with Cyberduck.
