Summary: Support for the recently announced Reduced Redundancy Storage (RRS) option to reduce costs by storing non-critical, reproducible data at lower levels of redundancy than the standard storage of Amazon S3 is now implemented in the latest nigthly snapshot build. To learn more about S3 support in Cyberduck, refer to the wiki.

Support for the recently [announced](http://developer.amazonwebservices.com/connect/ann.jspa?annID=687) Reduced Redundancy Storage (RRS) option to reduce costs by storing non-critical, reproducible data at lower levels of redundancy than the standard storage of Amazon S3 is now implemented in the latest [nigthly snapshot build](http://update.cyberduck.ch/nightly/).

![](http://sudo.ch/wp/uploads/2010/05/rrs.png "Reduced Redundancy Storage (RRS) option")

To learn more about S3 support in Cyberduck, refer to the [wiki](http://trac.cyberduck.ch/wiki/help/en/howto/s3).
