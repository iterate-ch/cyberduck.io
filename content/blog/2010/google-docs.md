As of the current [snapshot build](http://update.cyberduck.ch/nightly/), you can [enable support for Google Docs](http://trac.cyberduck.ch/wiki/help/en/howto/googledocs) to access your documents from within Cyberduck.

-   It allows you to download documents to various export formats.
-   Uploads documents to your Google Docs account for storage or choose to convert documents to Google Docs format.
-   Optionally convert images to Google Docs text document using Optical Character Recognition (OCR).

Read more about Google Docs support in the [Wiki](http://trac.cyberduck.ch/wiki/help/en/howto/googledocs). Note that this is a preliminary feature currently in development and might still have some quirks. Please [report](http://trac.cyberduck.ch/newticket) them to the issue tracker.
