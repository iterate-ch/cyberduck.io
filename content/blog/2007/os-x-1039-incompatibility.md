Summary: The current 2.8 beta build (3161) is incompatible with OS X 10.3.9 due to #1145 and #1155. Users not running OS X 10.4.x are advised not to upgrade to Cyberduck 2.8b1 yet.

The current 2.8 beta build (3161) is incompatible with OS X 10.3.9 due to [#1145](http://trac.cyberduck.ch/ticket/1145) and [#1155](http://trac.cyberduck.ch/ticket/1155). Users not running OS X 10.4.x are advised not to upgrade to Cyberduck 2.8b1 yet.
