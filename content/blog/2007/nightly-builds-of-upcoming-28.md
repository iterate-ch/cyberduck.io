Summary: Nightly builds of the upcoming 2.8 release are available (r2981). Changes include a new SSH library including the support for SCP transfers, transfer throttling, automatic reconnection on network failures, limiting the number of concurrent transfers and an outline view to browse the folder hierarchy in the overwrite warning and synchronizsation dialogs. Give it a try

Nightly builds of the upcoming 2.8 release are [available](http://update.cyberduck.ch/nightly/) ([r2981](http://update.cyberduck.ch/nightly/Cyberduck-2981.tar.gz)). [Changes](http://update.cyberduck.ch/nightly/changelog.html) include a new SSH library including the support for SCP transfers, transfer throttling, automatic reconnection on network failures, limiting the number of concurrent transfers and an outline view to browse the folder hierarchy in the overwrite warning and synchronizsation dialogs. Give it a try and [report any problems](http://trac.cyberduck.ch/).

**Update**: The latest build is [3084](http://update.cyberduck.ch/nightly/Cyberduck-3084.tar.gz).
